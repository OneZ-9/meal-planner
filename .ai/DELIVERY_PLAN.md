## Success measures

- **Functional** — signup → recipe → calendar assignment → shopping list →
  checklist works end to end without errors; shopping list merge output
  matches the verified algorithm test cases for same-family conversion.
- **Delivery** — all Must-haves and retained Should-haves shipped within the
  2-week window; Week 1 integration checkpoint met on schedule.
- **Process** — QA-identified risks resolved vs. explicitly accepted
  (currently 2 accepted: seeded-data correction, password reset) tracked
  openly, not discovered post-launch; actual time per module compared
  against this plan's estimate.
